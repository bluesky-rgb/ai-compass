# AI 探索罗盘

> 一个普通人在 AI 时代，从探索走向落地的长期指导与存档。

**在线阅读：[bluesky-rgb.github.io/ai-compass](https://bluesky-rgb.github.io/ai-compass/)**（按引导顺序阅读、查看学习地图、勾选行动清单）

这个仓库不放产品代码，只放**方向**：我是怎么判断的、为什么这样决定、接下来做什么、做完学到了什么。每次重要的讨论和决策都追加到这里，作为长期探索的指南针。

## 一句话

三条长期线同时推进：**能力线**补齐 AI 数据闭环，**IP 线**公开记录并积累信任，**落地线**用真实场景验证价值并走向盈利。前三个月另有一条**收入线**优先：求职和接单并行。

## 当前阶段

**2026-10-31**：完成整体规划。全职推进，储备约 3 个月，进入跑道期：收入优先，求职与接单并行。落地线进入第一个项目的阶段 0（服务第一位用户）；IP 线开始 X 重新定位；能力线停止每日新建研究仓库。

## 怎么维护

1. 每次重要讨论后，在 `logs/` 新增一份 `YYYY-MM-DD-主题.md`
2. 有新决定时，追加到 `decisions/决策记录.md`，写清理由和放弃的选项
3. 每两周更新一次 `docs/08-行动清单.md`，勾掉完成的，记录没完成的原因
4. 方向性的变化，回到 `docs/00`～`13` 修改，并在决策记录里说明
5. 网站首页的“当前阶段”“现在在做什么”“数据闭环现状”在 `assets/site.json` 里修改

网站本身（`index.html` 和 `assets/`）只负责展示，直接读取上面这些 Markdown 文件，不需要重新构建。新增一篇文档时，在 `assets/app.js` 顶部的 `PAGES` 列表里加一行即可。
