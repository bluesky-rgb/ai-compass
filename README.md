# AI 探索罗盘

> 一个普通人在 AI 时代，从探索走向落地的长期指导与存档。

这个仓库不放代码，只放**方向**：我是怎么判断的、为什么这样决定、接下来做什么、做完学到了什么。每次重要的讨论和决策都追加到这里，作为长期探索的指南针。

## 一句话

三条线同时推进：**能力线**补齐 AI 数据闭环，**IP 线**公开记录并积累信任，**落地线**用真实场景验证价值并走向盈利。

## 当前阶段

## 怎么维护

1. 每次重要讨论后，在 `logs/` 新增一份 `YYYY-MM-DD-主题.md`
2. 有新决定时，追加到 `decisions/决策记录.md`，写清理由和放弃的选项
3. 每两周更新一次 `docs/08-行动清单.md`，勾掉完成的，记录没完成的原因
4. 方向性的变化，回到 `docs/01`～`07` 修改，并在决策记录里说明
