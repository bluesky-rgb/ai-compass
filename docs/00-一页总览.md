# 00 一页总览

*截至 2026-10-31。只有一页，忘了方向时先读这里。*

## 我是谁，现在在哪

- 2026 年 7～10 月：95 个公开仓库、约 650 项研究、400 多个演示，研究过约 500 个开源项目
- 现在：失业，全职推进，储备约够 3 个月生活

## 核心判断

1. **AI 是工具，数据是原料，真实场景决定价值。**
2. 人处理信息分四步：获取、消化、展示、交互。我展示最强，消化最弱，真实数据空白。
3. AI 让执行变便宜，人的价值在于发现问题、判断取舍、连接真实世界、为结果负责。
4. 单纯用 AI 做 3D 产品，真实场景价值不够，不作主线。

## 路线：一条短期线 + 三条长期线

| 线 | 是什么 | 现在做什么 |
| --- | --- | --- |
| **收入线**（前三个月优先） | 求职和接单并行，保证跑道 | 写简历、整理接单作品集、投递、联系 10 个潜在客户 |
| 落地线 | 用真实场景验证价值并走向盈利 | 第一个项目：科研新手助手，把领域地图交给研究生 |
| IP 线 | 公开构建者：公开记录从探索走向产品 | X 重新定位，发置顶串推，每周至少 3 条 |
| 能力线 | 按数据闭环补短板 | 停止每日新仓库，只学能用在订单和课题上的东西 |

## 三个检查点

| 时间 | 看什么 |
| --- | --- |
| 约 2026-11-28 | 有没有接单意向或面试邀约 |
| 约 2026-12-26 | 有没有稳定收入来源 |
| 约 2027-01-23 | 跑道见底前必须有收入 |

## 四条原则

1. **先人工，后自动**：用户反复用到的部分才写成代码。
2. **每个阶段有过关条件**：没达到就不进入下一阶段，避免停在 80%。
3. **研究先问三个问题**：补哪一环？能用在项目上吗？有真实数据吗？并记录“能力前后”。
4. **公开失败**：放弃的方向和失败案例照样写出来。
