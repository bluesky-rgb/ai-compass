# 06 基础设施

**服务器在落地项目的阶段 2 再买，阶段 0 和 1 用现有工具人工完成就够了。** 早买不会出错，但会诱导先去搭系统，而不是先服务用户。

## 整体架构

- **个人主页和作品集**：继续用 GitHub Pages，免费，绑自己的域名
- **产品后端**：一台云服务器，跑数据库、课题知识库、论文定时获取任务和后台接口
- **模型能力**：调用模型 API（比如常用的 MiniMax），不在服务器上自己跑大模型
- **用户数据**：只放服务器，绝不进公开仓库

## 服务器怎么选

| 选择 | 优点 | 代价 |
| --- | --- | --- |
| 国内机房 | 国内用户访问快 | 绑定域名对外服务需要 ICP 备案，通常要几周 |
| 香港或海外机房 | 免备案，立刻能用 | 国内访问略慢，部分网络环境不稳定 |

用户是国内研究生，长期应选国内并办理备案；阶段 2 想先跑起来，可以先用香港，同时提交备案。

## 参考价格

按阿里云开发者社区 2026 年 5 月的文章，轻量应用服务器 2 核 4G 新用户活动价约 199 元/年，日常价约 70 元/月（[来源](https://developer.aliyun.com/article/1736611)）。活动价经常变化，以下单时为准。起步配置 2 核 4G 足够。

## 每月成本估算

服务器几十元，域名每年几十元，模型调用按用量计费。阶段 2 预计每月一两百元以内即可起步。

## 开发环境

目前主要在 iPad 上开发，浏览器和自动化工具受限。需要用到电脑上的 Claude 桌面版（内置浏览器）或 Chrome 插件时，再切换到电脑。
