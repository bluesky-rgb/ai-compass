# 05 落地线 · 第一个项目：科研新手助手

**服务对象：准备考博、刚开始做科研、还不会用 AI 的研究生。** 第一位用户是一名水生毒理学方向的研究生，他代表了一整类人。

## 需求来源

这位研究生想考博，需要研究学术论文，但论文的获取、理解、扩展和研究都需要一定能力。他对 AI 还很陌生，是一个完全的新手。

用“最懒”的方式拆解，他需要三件事：

1. **获取**与主题相关的论文
2. **解析**论文：不只是翻译和总结，还包括图表和数据
3. 用 **AI 协助**他更好地做研究

## 新手的六步路径（产品主流程）

1. **入门**：AI 能帮什么，科研的基本方法（怎么找、怎么读、怎么核对）
2. **看全景**：这个学科有哪些方向（已完成：[水生毒理学领域地图](../research/水生毒理学领域地图.md)）
3. **选方向**：结合兴趣、实验条件、目标导师收窄
4. **课题入门包**：核心论文清单、逐篇中文解读、术语表
5. **持续跟踪**：新论文自动推送，读过的沉淀进课题知识库
6. **写与申博**：综述、开题报告、研究计划的辅助修改（不代写）

## 能力地图

| 环节 | 他要做的事 | 已有基础 |
| --- | --- | --- |
| 找 | 中英文检索、顺着引用找、新论文推送 | `paper-research-workbench`（Europe PMC 检索 50～100 篇、去重、排序） |
| 读 | 解析全文、翻译、提取图表和数据、术语表 | nativePDF-structurer（`0828`）、PDF Craft（`0916`）、BabelDOC（`0823`） |
| 管 | 文献库、标签、笔记 | `file_read_on_web` 资料浏览器 |
| 想 | 基于课题知识库问答、找研究空白、对比方法 | LLM Wiki（`0829`）、Graphify（`0911`）、学术研究 Skill（`1025`） |
| 写 | 综述、开题报告、研究计划 | 学术研究 Skill（`1025`）、RD-Agent（`0925`） |

**最大的新增工作**：课题知识库、图表数据提取。

在 `1022`（Auto Paper Digest）和 `1025`（学术研究 Skill）里已经用水生毒理学做过实测。

## 设计原则

- **带路，不给工具箱**：新手需要被一步步领进门
- **交付物用他熟悉的形式**：PDF、Word、清单、对话，而不是仪表盘
- **英文自动、中文手动**：英文论文通过 PubMed、Europe PMC、OpenAlex 等正规接口自动获取；中文论文（知网、万方、维普没有开放接口且禁止批量抓取）由用户用学校账号下载后导入。**不爬知网。**
- **先人工、后自动**：他反复用到的部分，才值得写成代码

## 分阶段

每个阶段都有过关条件，没达到就不进入下一阶段。

1. **阶段 0 · 服务一个人（第 1～2 周）**
   做什么：和他沟通，人工完成领域地图、选方向、课题入门包。
   过关条件：他选定了方向，并且真的在读入门包里的论文。
2. **阶段 1 · 验证一类人（第 3～6 周）**
   做什么：通过他找到同学和同类研究生 5～10 人，继续人工服务，**从第 3 周起就开始小额收费**（受跑道约束，不再等待）。
   过关条件：至少 3 人付费，或持续回来使用。
3. **阶段 2 · 把重复的部分自动化（第 2～3 个月）**
   做什么：购买服务器，搭建“论文获取 → 解析 → 课题知识库”管线，做一个最简单的网页。
   过关条件：做一份课题入门包的人工时间明显下降，比如从一天降到一小时。
4. **阶段 3 · 产品化与盈利（第 4～6 个月）**
   做什么：上线独立站，提供订阅，尝试面向实验室和导师的版本。
   过关条件：每月收入覆盖服务器、模型调用和推广成本。

## 和用户沟通时要问的

- 本科和硕士专业、做过哪些实验
- 现在所在实验室有什么设备，导师做什么方向
- 有没有想考的学校或导师
- 英文论文能读到什么程度
- 每周能投入多少时间
- 用电脑和手机的习惯，对 AI 有没有顾虑

重点问过去的行为，而不是想法：上一次找论文怎么找的、花了多久、读不懂时怎么办、有没有为此花过钱或求过人。

## 合规边界

只做学习辅助和方法指导，不代写论文，不承诺录取。
