# 03 长期路线：三条线

**三条线互相供给：能力线提供本事，落地线提供真实问题和收入，IP 线把两者变成信任和影响力。**

> 前三个月受跑道约束：方向不变，以产品和能力构建为核心，收入从落地线（产品与定制服务）中来；时间分配和检查点见 [13 跑道约束与保底](13-三个月跑道计划.md)。

| | 0～3 个月 | 3～6 个月 | 6～12 个月 |
| --- | --- | --- | --- |
| **落地线** | 第一个项目：科研新手助手，人工服务验证 | 第一个项目开始收费；建立需求发现机制，筛选第二个场景 | 两到三个真实场景，至少一个持续盈利 |
| **能力线** | 停止每日新仓库，研究合并到一个库；重点补“消化”：知识库、文档解析、记忆 | 搭建可复用的“获取 → 消化 → 知识库”底座 | 底座能快速接入新行业，形成自己的方法论和工具集 |
| **IP 线** | X 重新定位，每周稳定发帖；个人主页改版上线 | 小红书、知乎开始面向产品用户；形成固定内容栏目 | 有稳定的关注者和私信咨询；IP 本身带来合作和客户 |

## 能力线：研究方式要变

以后每研究一个项目，先回答三个问题。答不出来，只记笔记，不做完整演示。

1. 它补的是数据闭环里的哪一环？
2. 能不能用在正在做的落地项目上？
3. 有没有真实的数据可以接？

优先补的能力：

- **消化**：课题知识库、文档与 PDF 解析、图表数据提取、长期记忆
- **获取**：可持续运行的定时采集（论文、资讯）
- **交互**：基于知识库的问答和 Agent 执行

## 落地线：需求发现机制

科研新手助手之后，用同样的方法持续找下一个场景。

- **从身边的人出发**：一个用户背后是一个圈子（同学、导师、实验室、同行）
- **看人们已经在付钱的地方**：外包平台、二手平台、知识付费，花钱请人做的就是痛点
- **看招聘信息**：企业花钱招人做的重复性工作，就是 AI 能切入的地方（可以用已有的 `job-change-observatory` 岗位变化观察站）
- **看社区里的抱怨**：小红书、知乎上人们主动吐槽的问题

**判断标准只有一条**：对方是不是已经在花时间或花钱解决它。是，就值得深挖；只是“觉得有用”，就先放一放。

### 有价值产品的四个筛选条件

1. **真实需求**：有一群人反复用，或者愿意为它付钱
2. **自己的优势**：别人不容易做，而我恰好擅长
3. **一个人做得动**：几周内出第一版，之后能持续迭代
4. **和 IP 同向**：做它的过程本身就是好内容

### 候选行业

客服、教育等行业作为候选，等有真实入口（认识的人、能拿到的真实数据）再进入。它们底层是同一套能力：**把一个组织的资料变成知识库，再让 AI 基于它回答和生成。** 这正是能力线要建的底座。

| | 客服 | 教育 |
| --- | --- | --- |
| 谁付钱 | 企业、商家 | 机构、学校，或家长 |
| 现成数据 | 产品文档、FAQ、历史聊天记录 | 教材、题库、学生作答记录 |
| 价值怎么算 | 减少人工、响应更快，好量化 | 提分、省老师时间，较难证明 |
| 难点 | 竞争激烈 | 获客难，内容要合规 |
| 切入点 | 某个细分行业的中小商家 | 给老师和机构用的工具 |
