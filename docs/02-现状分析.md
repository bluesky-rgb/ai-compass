# 02 现状分析

*截至 2026-10-31*

**最大的资产是“快速吃透陌生技术”的能力和四个月的公开积累；最大的问题是精力分散、没有真实用户、对外几乎没有曝光。**

## 积累

2026 年 7 月到 10 月：

- 95 个公开仓库
- 约 650 项研究与实验，其中 400 多个可在线打开的演示
- 研究对象覆盖约 500 个上游开源项目
- 几乎每天新建一个研究仓库（`0801_githubcode_study` … `1025_codex_project`）

研究方法稳定：**跑通 → 拆原理 → 做演示 → 做自己的扩展**。

## 优势、短板、机会、风险

| | 内容 |
| --- | --- |
| 优势 | 学习和复现速度极快；有一套稳定的研究方法；展示能力强；能用中文把复杂技术讲清楚 |
| 短板 | 几乎每个项目停在 80%；没有持续的真实用户和真实数据；“消化”能力（知识库、记忆、结构化）最弱；习惯在 iPad 上开发，工具受限 |
| 机会 | 懂 AI 又懂某个行业真实问题的人很少；中文社区缺少“真跑过、真拆过”的内容；第一个真实用户（准备考博的研究生）已经出现 |
| 风险 | 继续每天开新仓库，积累会越来越散；只做展示层，容易陷入“好看但没用”；X 账号没有定位，曝光会一直起不来 |

## 按数据闭环看能力分布

| 环节 | 现状 | 代表项目 |
| --- | --- | --- |
| 获取 | 有基础 | `paper-research-workbench`（Europe PMC 检索）、`0711_news_codex`、`ai-frontier-radar` |
| 消化 | **最弱** | LLM Wiki（`0829`）、Graphify（`0911`）、PDF 结构还原（`0828`、`0916`），都停在研究阶段 |
| 展示 | 最强 | `ocean-world`、`plant-earth`、`tibet-explorer`、`0922` 太阳系等大量 3D、图表、视频演示 |
| 交互 | 有尝试 | `expert-decision-room`（共想室）、`desktop-girlfriend`、`m3_game_try_1` 多 Agent 推理游戏 |
| 真实数据 | **空白** | 几乎全是演示数据 |

## 对 3D 方向的结论

亲手做过大量 3D 作品后的判断：**单纯用 AI 做 3D 产品，真实使用场景很少，价值不够。** 3D 作品保留为阶段探索的展示和技术理解，不再作为主线投入。`0929_codexgpt6_3d_game_test` 已自行标注为失败案例。

## 真正有真实需求的已有项目

按“有人反复用”这个标准筛选：

- `ai_for_mytown`：AI 助农，父母种桃的真实场景
- `file_read_on_web`：资料浏览器，本地预览 Office 文档
- `yinglu-recorder`：映录，网页演示录制
- `ai-frontier-radar`：AI 前沿资讯编译
- `paper-research-workbench`：论文研究工作台，已成为第一个落地项目的基础
